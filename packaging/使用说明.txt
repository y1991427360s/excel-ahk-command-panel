自动化工具面板 · 朋友分享版

【安装只需两步】
1. 右键压缩包，选择“全部解压缩”。不要在压缩包内部直接运行。
2. 打开解压后的文件夹，双击“双击安装.cmd”，看到“安装成功”即可。

支持 64 位 Windows 10 / 11。表格功能需要 Microsoft Excel 或 WPS 表格桌面版；
Word/Excel 转 PDF 需要 Microsoft Office；CAD 图纸关闭/保存需要中望 CAD 或 AutoCAD。
自带 AutoHotkey v2，无需另外安装 AutoHotkey、Python，无需管理员权限，也无需联网下载组件。
双击安装通过自带运行环境直接执行，不依赖 PowerShell。安装期间不需要关闭 Excel 或 WPS。
安装目录为当前用户的 %LOCALAPPDATA%\SpreadsheetToolsShare。
安装后会自动启动，并创建桌面快捷方式和开机启动项。
以后可直接使用快捷键；如果手动退出过程序，双击桌面“自动化工具面板（分享版）”即可启动。
从旧版“表格工具面板”升级：直接安装本包即可，旧的桌面和开机启动快捷方式会自动换成新名字。
安装后可以删除原压缩包和解压文件夹。

【日常使用】
先选中要处理的东西 → 按 Ctrl+Shift+E → 面板自动切到对应页面 → 点击功能。
  · 在 Excel / WPS 里选中单元格：进入“表格工具”。
  · 在资源管理器或桌面选中文件：进入“批量改名”或“文件处理”（选中文件夹、PDF、Word、Excel 或压缩包时）；选中 DWG 进入“CAD 图纸”。
  · 在 CAD 窗口里按快捷键：进入“CAD 图纸”。
左侧栏可随时切换页面，Ctrl+Tab 也可切换；没有对应选区的按钮会变灰。
面板顶部会显示锁定的工作簿、工作表和选区。所有表格处理使用打开面板前锁定的范围。
打开面板后原表格高亮可能隐藏，不表示锁定的范围丢失。
未能锁定选区时按钮禁用，请返回表格重新选中后按快捷键。
两款表格同时打开时，先切换到要操作的表格窗口，再按快捷键。
操作不会自动保存工作簿，请自行检查后保存。

【包含功能】
表格工具：添加前缀、添加后缀、删除前端字符、删除末尾字符、删除括号内容并合并换行、
  去重整理、按电缆截面排序、标出重复项、比较两列差异、合并相同内容并居中、
  拆分合并单元格并填充、数字向上取十位、数字批量加减、导出选区信息（给 AI）、重复上次操作、撤销上次操作。
CAD 图纸：用默认程序或自选程序打开选中的 DWG；对中望 CAD / AutoCAD 当前图纸
  强制关闭、保存并关闭、保存并重开；电缆定义总览（配合 DDFD 电缆向导插件）。
批量改名：添加固定前缀/后缀、按顺序添加数字前缀、删除前端/末尾文字、替换文件名中的文字、
  将 ML 替换为目录。改名前会预览并确认，扩展名不变，文件夹自动跳过。
文件处理：合并选中的 PDF（按文件名顺序，确认框可滚动查看完整顺序）；统计图幅（PDF、文件夹或
  rar/zip/7z 压缩包里每页是 A0~A4 及加长几倍，可复制成打印明细表一行）；Word 转 PDF、
  Excel 转 PDF（整个工作簿）。都保存到同目录，覆盖前确认，源文件不修改。
  找出最新版本：选中文件夹（连同子文件夹）或几个文件，同名文件（忽略“- 副本”“(1)”“v2”、日期、“最终版”等后缀）
  归为一组，按修改时间标出最新那份；.bak 等备份文件不参与。
  结果窗口可最小化、缩放，支持搜索、按类型筛选、排序和“只看有多份的”；单击一行看它的全部副本，
  双击或按 Enter 在资源管理器里定位最新文件，只读不改文件。
默认输入法：一键切换 Windows“替代默认输入法”。

【撤销】
Excel：可按 Ctrl+Z，也可使用面板的“撤销上次表格操作”。
WPS：脚本操作请用面板的“撤销上次表格操作”；Ctrl+Z 仍由 WPS 自己处理。
脚本最多保留最近 10 次操作快照，退出程序后失效。
没有脚本撤销记录时，面板不接管 Excel 的 Ctrl+Z。
需要完全退出面板时，右键右下角托盘图标，选择“退出自动化工具面板”。

【电缆排序】
选择型号列即可自动连同右侧长度列排序；也可以直接选择这两列。
型号和长度成对移动，超过两列会拒绝执行。
3×25+1×16 和 3×50+1×25 均按截面 25 排列。

【标出重复项 / 比较两列】
标出重复项：选区内（只选一格时为所在整列）内容相同的单元格填黄色底。
比较两列差异：选中两列，只在一列出现、另一列找不到的单元格填浅红色底并列出清单。
只改底色，不改内容；比较时忽略首尾空格，空白单元格不参与。
两者都可用撤销按钮恢复原底色。

【CAD 图纸】
关闭/保存只作用于打开面板前所在 CAD 的当前图纸；中望 CAD 和 AutoCAD 同时运行时，请先切到要操作的 CAD 再按快捷键。
CAD 正在执行命令时会拒绝操作；“强制关闭”不保存、不确认，请谨慎使用。
保存通过 CAD 自己的 QSAVE 完成；未命名或只读图纸不会保存。
电缆定义总览：需要 CAD 里已加载 DDFD 电缆向导插件（本包不含插件）。在 CAD 里运行 DDFD，每标一个房间、
  柜子、通道或竖井，总览窗口就自动弹出并刷新；也可在“CAD 图纸”页点“电缆定义总览”手动打开。
  点条目或平面图上的对象会在 CAD 空闲时定位过去；右键柜子可设长度调整（需较新的插件版本）。

【合并 PDF / 统计图幅】
合并：至少选中两个 PDF；按文件名排序（和资源管理器“名称”排序一致），与点选先后无关。
统计图幅：页面短边决定 A4/A3/A2/A1/A0，长边按 0.25 倍算加长，例如 297×841 为 A3*2。
  结果框点“是”复制 A0 ~ A4 共 23 列数量，粘贴到打印明细表的 A0 列；点“否”复制完整文字。
  zip 直接读取；rar/7z 需要电脑装有 WinRAR 或 7-Zip（Windows 11 自带的解压组件通常也能处理）。
这两个功能由包内 pdf-tools.exe 完成，不需要安装 Python。

【数字加减】
输入正数增加，负数减少，支持小数；跳过空白、文字、公式和日期。
合并区域只修改一次，支持不连续选区；单次最多处理 10000 格使用区域。

【遇到问题】
快捷键没有反应：先双击桌面入口；检查是否与其他工具占用了 Ctrl+Shift+E。
无法连接表格：退出单元格编辑状态，重新选中单元格；两款程序尽量均以普通权限运行。
如 Windows 显示安全提示，请先确认压缩包来自你信任的发送者；公司策略禁止脚本时请联系管理员。
安装失败会显示错误弹窗；安装日志：%LOCALAPPDATA%\SpreadsheetToolsShare-install.log。
启动入口日志：%LOCALAPPDATA%\SpreadsheetToolsShare-launch.log。
再次安装会更新同一个分享版，不会关闭其他 AutoHotkey 脚本。
卸载：重新解压本包，双击“卸载.cmd”。

【说明】
本包不含依赖作者本机环境的功能：CAD 插件（LISP）重载与插件命令、电缆总览、AI 改 CAD 文字、批量转可信 DWG。
AutoHotkey 为独立开源运行环境，许可和源码链接位于 app 文件夹。
pdf-tools.exe 由 Python 与开源库 pypdf（BSD 许可）打包而成。
