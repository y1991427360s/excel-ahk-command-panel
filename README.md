# AutoHotkey 全局自动化工具面板

这是一个 AutoHotkey v2 全局自动化入口。按 `Ctrl+Shift+E` 可以在任意界面打开功能面板，面板按类别组织工具；表格工具同时支持 Microsoft Excel 和 WPS 表格。

面板沿用 Oracle-Sync 桌宠（`D:\Syncthing\Oracle-Sync\tools\pets`）右键菜单的浅色卡片风格：白底、浅灰描边圆角按钮，按钮左侧是 Segoe MDL2 线性图标，悬停时底色变浅灰、图标变蓝并显示手形光标，顶部选区信息行为浅灰底；左侧边栏切换“表格工具 / 打开图纸 / 批量改名 / 文件处理 / 默认输入法 / 使用说明”，右侧顶部显示打开前识别到的选区（工作簿、工作表和单元格地址，或选中的文件）。打开时自动切到对应页面：表格选区进入“表格工具”，选中 DWG 进入“打开图纸”，全是 PDF/Word/Excel 文件进入“文件处理”，其他文件进入“批量改名”；没有选区时回到上次使用的页面。没有对应选区的按钮会变灰，撤销按钮在没有可撤销操作时也会变灰。`Esc` 关闭面板，`Ctrl+Tab` / `Ctrl+Shift+Tab` 切换页面。界面组件位于 `src\modern-panel-ui.ahk`：所有元素用 GDI+ 画进预乘透明通道的画布，经 BufferedPaint 交给 DWM 合成，点击与悬停按坐标自行判断，无第三方依赖；另保留两套主题，可在脚本里调用 `ModernPanelTheme("glass")`（仿 iOS 26 液态玻璃）或 `ModernPanelTheme("light")`（浅灰底白色圆角）切换，分享版共用同一套组件；表格按钮区由 `@@SPREADSHEET_BUTTONS_BEGIN/END` 标记，供 `packaging\build-share.py` 提取。

## 功能

- `Ctrl+Shift+E`：全局打开自动化工具面板
- `打开图纸`
  - 在资源管理器或桌面选中一个 `.dwg` 文件后，面板显示所选文件名
  - 可选择 AutoCAD 2018、中望 CAD 2026 或 CAD快速看图打开
  - **重新加载 AA整合版本.lsp (中望 CAD)**：一键通知当前运行中的中望 CAD 2026 自动加载/重载 `D:\Syncthing\Oracle-Sync\LISP\ZW-auto_lisp\AA整合版本.lsp`，无需拖拽文件或手动敲命令
  - **CAD 里正在编辑的图纸**：强制关闭（不保存）、保存并关闭、保存并重开，三个按钮单独成组，与重载插件按钮分开放置
- `表格工具（Excel / WPS）`
  - 添加前缀
  - 添加后缀
  - 删除前端字符
  - 删除末尾字符
  - 去重整理
  - 删除括号内容并合并换行
  - 按电缆截面排序
  - 合并相同内容并居中
  - 拆分合并单元格并填充
  - 数字向上取十位
  - 数字批量加减
  - 撤销上次表格操作
  - 导出选区信息（给 AI）：预览、复制或保存包含内容、格式及表格状态的文本
- `批量修改文件`
  - 给资源管理器或桌面选中的文件名添加固定前缀
  - 给资源管理器或桌面选中的文件名添加固定后缀
  - 按文件名顺序添加数字前缀，例如 `1文件名.xlsx`、`2文件名.xlsx`
  - 删除文件名末尾指定数量文字
  - 删除文件名前端指定数量文字
  - 一键将文件名中的 `ML` 替换为 `目录`
  - 按输入内容查找并替换文件名文字
- `文件处理`
  - 按资源管理器当前选中顺序合并多个 PDF，并输入输出文件名
  - 将选中的 Word 文档批量转换为同名 PDF
  - 将选中的 Excel 工作簿（含隐藏工作表）批量转换为同名 PDF
- `默认输入法`
  - 一键修改 Windows“替代默认输入法”，或恢复为“使用语言列表(推荐)”
  - 列表随安装/卸载的输入法自动更新；已安装但未加入输入法列表的会标“（未添加）”，点击时先添加再设为默认
- Excel 脚本操作后可按 `Ctrl+Z` 撤销；WPS 使用面板里的“撤销上次表格操作”

## 打开 DWG 图纸

先在资源管理器或桌面选中一个 `.dwg` 文件，再按 `Ctrl+Shift+E`。面板的“打开图纸”页会显示当前文件名，并提供 AutoCAD（2018）、中望 CAD（2026）、快速看图（CAD快速看图）三个打开按钮。

没有选中 DWG 时三个按钮保持禁用。该功能只把当前选中的文件路径传给所选软件，不修改或保存图纸。

每次按快捷键都会重新读取当时的资源管理器或桌面选区，不沿用上次打开的图纸。读取过程中会自动恢复原剪贴板，并避免把临时文件路径写入 CopyQ 历史。 CopyQ 调用设有超时；原本已暂停监控时保持暂停，只恢复由面板暂停的监控。

## 强制关闭 / 保存并关闭 / 保存并重开当前图纸

“打开图纸”页“CAD 里正在编辑的图纸”一栏有三个按钮，通过 COM（`ZWCAD.Application` / `AutoCAD.Application`）操作 CAD 的**当前活动图纸**：

- **强制关闭**：不保存直接关闭（`Document.Close(False)`）。不弹确认，未保存的修改直接丢弃。
- **保存并关闭**：向 CAD 命令行发送 `_.QSAVE` 与 `_.CLOSE`，由 CAD 自己保存并关闭，面板等待图纸关闭后在托盘提示（最多等 3 分钟）。不从面板进程调用 COM `Save()`：2026-10-28 中望 CAD 2026 用它保存 26MB 图纸时直接崩溃，原生 `QSAVE` 正常。
- **保存并重开**：同上保存并关闭，再按原完整路径 `Documents.Open` 重新打开并切回 CAD。
- 2026-10-28 已在中望 CAD 2026 上用 26MB 测试图实测三个按钮：保存并重开约 8 秒，强制关闭不写文件，保存并关闭约 2 秒，CAD 无异常。
- 两个保存按钮遇到从未保存过的新图纸、只读打开的图纸会直接提示而不做任何操作；保存失败时不关闭图纸。
- 为防止重载插件时误点关闭图纸，这三个按钮与页面最下方的“重新加载 AA整合版本.lsp”按钮之间隔着“文字联动标记”一组。
- **操作哪个 CAD**：在 CAD 窗口里按 `Ctrl+Shift+E` 时，面板直接进入“打开图纸”页并操作该 CAD；不在 CAD 窗口时，只有一个 CAD 在运行才自动选它，中望 CAD 和 AutoCAD 都在运行时不猜测，会提示先切到目标 CAD 窗口。
- CAD 正在执行命令（`CMDACTIVE ≠ 0`）时拒绝操作，请先按 Esc。

## 重新加载 AA整合版本.lsp (中望 CAD)

在“打开图纸”页中点击 **“重新加载 AA整合版本.lsp (中望 CAD)”** 按钮，AHK 将直接通过 COM 自动化接口（`ZWCAD.Application`）向运行中的中望 CAD 发送 `(load "D:/Syncthing/Oracle-Sync/LISP/ZW-auto_lisp/AA整合版本.lsp")` 指令。
- **无需手动拖拽**：在编辑器中修改或保存脚本后，随时按 `Ctrl+Shift+E` 点击此按钮即可完成热更新。
- **状态通知**：执行成功后屏幕右下角托盘弹出提示气泡；若未开启中望 CAD 或无打开图纸，会弹出明确提示。

## CAD 结果卡片（中望 CAD 命令明细）

中望 CAD 的 `BH1`、`BH2`、`BHG`、`BH3`、`JM` 运行结束后，命令行只留一行汇总，明细写进 `%TEMP%\AA-CAD-Report\report.txt`。面板脚本常驻时每 0.5 秒检查一次：

- 有新结果且有明细时，在 CAD 主窗口右上角弹出“CAD 结果”卡片（不抢焦点）：标题是命令名、图纸名和时间，下面一行汇总，再列出明细，问题（红）、提醒（橙）在前，正常（绿）、说明（灰）在后；每页 8 条，可翻页。
- **点条目定位**：确认 CAD 空闲（没有正在执行的命令）后，切到结果所属的图纸，发送 `(aa:rep-zoom "句柄")`，缩放到该对象并选中；CAD 正在执行命令、图纸没打开或对象已删除时只在托盘提示，不往命令行里打字。
- **复制**：每条右侧的复制按钮复制这一条（`[命令] 类别：文字（图纸 …，句柄 …）`）；底部“复制全部”复制标题、图纸路径、汇总、完整统计、全部明细（不分页，带序号和级别）和说明，方便整段发给别人判断问题。复制后托盘提示。
- 下一次命令没有明细时，旧卡片自动收起；也可以点“关闭”。
- 卡片与主面板可同时存在：`ModernPanelCreate` 的第三个参数 `keep` 为真时登记为常驻小窗，打开主面板不会清掉它。
- 冒烟测试（不连接 CAD）：`AutoHotkey64.exe tests\cad-report-card-smoke.ahk <输出目录>`，会把卡片画布存成 PNG 并输出 PASS/FAIL。

## 表格工具说明

### 导出选区信息（给 AI）

在 Excel/WPS 中选中需要说明的单元格，按 `Ctrl+Shift+E`，在“表格工具”点击“导出选区信息（给 AI）”。预览窗口支持“复制给 AI”和“另存为文本…”，默认保存到系统文档目录，文本使用带 BOM 的 UTF-8。

导出保留原表坐标、显示文字、原始值、公式、合并区域及其内容来源；以格式编号引用字体、字号、加粗、对齐、换行、数字格式、字体颜色、底色和边框。还包含行高、列宽、隐藏状态、筛选范围与已启用条件、结构化表及其筛选、冻结窗格和网格线等状态。优先读取包含条件格式效果的显示格式，不支持时回退基础格式；不支持或读取失败的属性明确标记为“不可读取”。筛选操作符和部分格式属性保留 Excel 数值编码。

多个不连续选区分别读取，未选中的普通单元格不读取。隐藏行列中的单元格单独列出，便于 AI 区分可见内容和筛选隐藏内容。合并区域与选区相交时，读取该区域左上角的文字并标明完整合并范围。普通选区保留空白格；整行/整列选区只导出与 UsedRange 相交部分。为避免逐格读取格式造成长时间卡顿，超过 10000 格会要求缩小选区，不会静默截断。

导出只读，不修改或保存工作簿。导出的是文本描述，不包含浮动图片、图形、图表或批注，也不逐字符描述混合字体。窗口状态取该工作簿第一个窗口，并在文本中注明。需要精确展示图形时可同时提供截图。

表格工具会根据按下 `Ctrl+Shift+E` 时所在的窗口连接 Excel 或 WPS。两者同时运行时，只操作打开面板前所在的表格，避免连接到错误工作簿。添加前缀、添加后缀、删除前端字符、删除末尾字符和合并相同内容会在面板打开时锁定原选区，之后只处理当时真正选中的单元格；多个不连续选区之间未选中的单元格不会处理。

拆分合并、删除括号内容、电缆排序和去重整理也统一使用打开面板前锁定的选区，不再读取按钮点击后的实时选区。去重整理继续按原规则整理锁定列从第 2 行开始的数据。分享版下方显示已锁定的工作表与地址，锁定失败时禁用操作按钮；初次显示面板不抢焦点，原表格高亮因焦点变化隐藏也不影响目标范围。没有脚本撤销记录时不拦截 Excel 的 `Ctrl+Z`。可运行 `tests\split-compat-smoke.ps1 -SelectionSnapshot`，在独立临时工作簿验证选区/活动工作簿改变后，拆分、填充、撤销、括号清理和电缆排序仍处理原范围。该测试仅替换 COM 连接目标以隔离用户工作簿，不代表 Excel 2016 实机验收。

“添加前缀”和“添加后缀”会把使用者输入的文字添加到每个选中单元格的开头或结尾。空白单元格和公式单元格不会修改。

文字操作（前后缀、删除字符、括号清理）统一将锁定选区裁剪至 UsedRange；实际使用范围超过 10000 格时要求分批处理。普通常量按连续区域批量读写，公式和空白跳过，未发生变化的单元格保持原类型及格式；合并块只处理一次并保持合并。写入前先完整记录撤销，执行失败时自动回滚；回滚受保护等原因阻止时保留快照，解除阻碍后可使用面板撤销。括号清理的撤销同时恢复原自动换行设置；撤销和失败回滚也保留 `=1+1`、`00123` 等文字的原始类型。处理结果按文字写入，以 `=` 开头也不会被当作公式。

去重整理先批量读取目标列，再一次性写回整理结果和空白尾部，取消原先“清空后逐格写回”的流程；写回失败时自动回滚，回滚失败时保留撤销快照。待整理列包含合并单元格时会要求先拆分。

“删除前端字符”和“删除末尾字符”会让使用者输入要删除的字符数，再批量处理选中的单元格。例如删除前端 `2` 个字符时，`AB时间同步柜` 会变成 `时间同步柜`；删除末尾 `5` 个字符时，`时间同步柜2-36n` 会变成 `时间同步柜`。删除数量大于或等于单元格文本长度时，单元格会变为空白。

“删除括号内容并合并换行”会处理当前选中的单元格，删除半角/全角小括号及其中的文字，并把剩余内容合并成一行。例如 `110kV母线智能汇控柜` + 换行 + `（PT合并单元）` 会变成 `110kV母线智能汇控柜`。

“合并相同内容并居中”支持一个连续的单列或多列选区。多列选区会按列独立处理，不会横向合并；脚本会在每一列中从上到下查找连续且实际值完全相同的单元格，每一段至少包含两个单元格时才纵向合并，并把内容设置为水平、垂直居中。空白单元格会中断分组，单独出现的值保持不变；大小写不同或首尾空格不同的文字不会视为相同。脚本还会读取工作表的横向分页符，分页符上下的内容不会跨页合并，而是分别形成独立的合并区域。为避免内容或公式丢失，不连续选区、公式单元格以及已经合并的单元格都会被拒绝。

“拆分合并单元格并填充”会处理选区内一个或多个合并区域。每个合并区域拆分前会先读取左上角单元格的内容，拆分后再把该内容写入原合并区域里的每一个单元格。例如一个由 5 个单元格合并而成、内容为“变压器”的区域，拆分后 5 个单元格都会填入“变压器”。选区里的普通未合并单元格不会修改；只要选区与某个合并区域相交，就会完整处理该合并区域。该操作不会自动保存工作簿，并支持现有的 Excel/WPS 撤销方式。

合并信息按完整 XML 标签解析，兼容多个标签处于同一行或属性跨行的输出；若 XML 未识别出合并块，会自动使用 COM 兼容检测，避免整列选区误报“没有合并单元格”。运行 `powershell -ExecutionPolicy Bypass -File tests\split-compat-smoke.ps1` 可验证整列、非 A1 起点、混合普通行、不同 XML 格式、回退检测、填充与撤销；加 `-LegacyParser` 可复现旧解析器在紧凑 XML 下的失败。该测试模拟返回格式差异，不代表已在 Excel 2016 实机验收。

“数字向上取十位”要求选区内所有单元格都是原生数值。只要选区中有空白、文字、公式或日期格式单元格，整批操作会取消，不修改任何内容。处理时按数学上的向上取整到 10 的倍数计算，例如 `331` 变成 `340`、`982` 变成 `990`、`2617` 变成 `2620`，已经是 10 的倍数的数值保持不变。负数和小数也按同一规则处理，只写回数值并保留原有显示格式。该操作会记录到脚本撤销栈，Excel 可按 `Ctrl+Z` 撤销，WPS 使用面板撤销按钮。

“数字批量加减”处理打开面板时锁定的选区，输入正数表示增加，负数表示减少，支持小数。例如选中的编号为 `8、9、10、11、12、13`，输入 `-2` 后变成 `6、7、8、9、10、11`。合并区域只计算一次，仅修改左上角数值，保持合并状态、格式及行列设置；即使只选中合并区域的一部分，也会处理该合并区域的数值。空白、文字（含以文本存储的数字）、公式和日期格式单元格跳过，隐藏行列中的选中数字也会处理。支持不连续选区，整行/整列裁剪至 UsedRange，使用区域超过 10000 格时要求分批处理。输入 `0` 不做修改，失败时尝试回滚，不自动保存工作簿。Excel 可按 `Ctrl+Z` 撤销，WPS 使用面板撤销按钮。

数字加减回归测试：`powershell -ExecutionPolicy Bypass -File tests\numeric-offset-smoke.ps1 -Provider excel`，WPS 将最后参数换为 `wps`。测试载入生产函数，使用独立临时工作簿检查合并区域去重、正负数与小数、不连续/部分合并选区、整列、跳过非数值以及撤销和格式，不修改用户工作簿。

“按电缆截面排序”按相邻的两列处理一条完整记录：左列是“电缆型号及截面”，右列是“电缆长度”。可以只选型号列，脚本会自动把右侧长度列纳入排序；也可以直接选中型号和长度两列。型号与长度始终同步移动，避免排序后长度错配。为防止把旁边另一组独立清单一起移动，选区超过两列时会拒绝执行。排序规则为：

- 有效截面从小到大，例如 `×1.5`、`×2.5`、`×4`
- 截面相同时，总芯数从少到多，例如 `4×1.5`、`7×1.5`、`10×1.5`
- `3×25+1×16` 默认按主芯截面 `25` 排列
- `3×50+1×25` 使用特殊规则归入截面 `25`，不归入 `50`
- 无法识别的行保持原相对顺序并移到选区末尾

型号解析支持 `×`、`x`、`X`、`*` 作为乘号，也支持小数截面和 `3×25+1×16` 形式的复合规格。选区第一行包含“电缆型号”或“规格”等表头文字时，脚本会保留表头不动。

说明：COM 写入可能清空表格软件的原生撤销栈，所以脚本内部最多保留 10 次脚本操作快照。Excel 中按 `Ctrl+Z` 时，会先检查 Excel 当前是否有原生撤销内容；如果有，就交回 Excel 原生撤销；如果没有，才恢复上一次脚本修改。WPS 不提供同等可靠的原生撤销状态接口，因此 `Ctrl+Z` 保留给 WPS，自定义脚本撤销通过面板里的“撤销上次表格操作”执行。

正常执行功能和脚本撤销完成后不会弹出完成提示；只在需要用户输入、操作前确认、参数错误或执行失败时弹窗。

## 批量修改文件说明

先在资源管理器或桌面选中文件，再按 `Ctrl+Shift+E` 打开面板，在左侧边栏进入“批量改名”页（选中普通文件时会自动进入）。面板打开时会保存当时的文件选区；更改选区后重新打开面板即可更新快照。

批量改名前会显示预览并要求确认。脚本会保持原扩展名不变，并在执行前检查：

- 目标文件名是否重复
- 目标文件是否已经存在
- 输入的前缀、后缀或分隔符是否包含 Windows 文件名非法字符

当前批量改名只处理文件，文件夹会自动跳过。

删除前端或末尾文字时，只处理文件主名，扩展名保持不变。例如对 `示例文件.xlsx` 删除末尾 2 位，会得到 `示例.xlsx`。

“替换文件名中的文字”会让使用者输入查找内容和替换内容，按普通文字匹配文件主名（不区分大小写），扩展名不参与替换并保持不变。替换内容可以留空以删除匹配文字。执行前会显示改名预览并要求确认，也会检查目标重名和已存在文件。

## 文件处理说明

PDF 合并、Word 转 PDF 和 Excel 转 PDF 位于“文件处理”页。先在资源管理器或桌面选中文件，再打开面板；选中的全是 PDF、Word 或 Excel 时会自动进入该页。

“合并选中的 PDF”要求至少选中两个 PDF。合并顺序与资源管理器/桌面当前选中顺序一致，输出到第一份 PDF 所在文件夹；文件名可以输入或直接使用默认的“合并结果.pdf”。若目标文件已存在，会先询问是否覆盖；确认后先写入临时文件，成功后再替换目标。源 PDF 不会修改。此功能调用系统 `python`，并要求该 Python 环境安装 `pypdf`。

“Word 转 PDF”支持选中的 `.doc`、`.docx` 和 `.docm` 文档，可一次转换多个文件。检测到多个不同文档时会先展示文件清单供确认。PDF 输出到各 Word 文档所在文件夹，并沿用原文件名；若同名 PDF 已存在，会先询问是否覆盖。此功能通过 Microsoft Word 导出 PDF，要求本机安装 Microsoft Word，源文档以只读方式打开且不会被修改。选区和转换诊断日志保存在 `%LOCALAPPDATA%\AutoHotkeyPanel\selection-debug.log`。

“Excel 转 PDF”支持选中的 `.xls`、`.xlsx`、`.xlsm` 和 `.xlsb` 工作簿，可一次转换多个文件。检测到多个不同工作簿时会先展示文件清单供确认。每个工作簿的所有工作表（包括隐藏工作表）会导出到一个 PDF，输出到工作簿所在文件夹并沿用原文件名；若同名 PDF 已存在，会先询问是否覆盖。此功能通过 Microsoft Excel 导出 PDF，要求本机安装 Microsoft Excel。工作簿以只读方式打开，不保存源文件；导出期间会临时显示隐藏工作表并在导出后恢复其原状态。若工作簿结构保护阻止显示隐藏工作表，该工作簿会转换失败且源文件不会修改。

## 默认输入法说明

“默认输入法”页等同于 设置 → 时间和语言 → 输入 → 高级键盘设置 → 替代默认输入法。打开面板时从注册表 `HKCU\Control Panel\International\User Profile` 读取已安装输入法和当前设置（不启动 PowerShell），当前项标“（当前）”并变灰。除了语言列表（Win+空格）里已添加的输入法，还会扫描 `HKLM\SOFTWARE\Microsoft\CTF\TIP` 中为该语言注册、但尚未加入列表的输入法（例如刚安装的豆包输入法），标“（未添加）”；点击这类项会先用 `Set-WinUserLanguageList` 把它加入该语言的输入法列表，再设为默认。每次打开面板都重新读取，装上或卸载输入法后列表自动增减。点击其他项时调用系统 `Set-WinDefaultInputMethodOverride` 写入，写入后再读回注册表核对，成功后关闭面板并弹出托盘提示。“使用语言列表(推荐)”会清除替代设置。新设置对之后新打开的窗口生效，已打开窗口的当前输入法不变。实现位于 `src\input-method-switch.ahk`。

## 便携部署

项目现在按“整个文件夹可迁移”的方式组织。主脚本直接从本项目的 `src\excel-command-panel.ahk` 运行，安装脚本不会再把脚本复制到 `Documents\AutoHotkey`。

在 PowerShell 中运行：

```powershell
Set-Location E:\366256\vibecoding\AutoHotkey\projects\excel-ahk-command-panel
.\install.ps1
```

安装脚本会：

- 先执行 AutoHotkey 静态加载检查；检查失败时保留当前运行面板和启动项
- 创建或更新开机启动项 `excel-command-panel.lnk`
- 让启动项直接指向当前项目里的 `src\excel-command-panel.ahk`
- 停用旧的 `excel-prefix-selected-cells.lnk` 和 `excel-dedupe-sort-b-column.lnk`
- 仅按完整路径重启本项目主脚本，以及系统文档目录 `AutoHotkey` 下的旧面板和两份已退役脚本，避免影响其他目录的同名脚本
- 通过资源管理器启动常驻面板，并确认对应进程持续存活后才报告成功；启动失败会明确报错

如果移动到其他电脑或其他路径，只要 AutoHotkey v2 已安装，进入新路径后重新运行 `.\install.ps1` 即可。

## 自动化测试

### 分享给其他电脑（只含表格功能）

运行 `python packaging\build-share.py --output <输出目录>`，生成自带 AutoHotkey v2 64 位运行环境的 ZIP 分享包。构建时会下载与本机运行环境版本对应的 AutoHotkey 开源源码包，供随包分发；朋友安装时无需联网或另装 AutoHotkey。

分享版从现有生产源码提取表格按钮及依赖函数，不包含 CAD、LISP、文件改名与 PDF 工具，也不携带个人路径或全局记忆。朋友解压后双击 `双击安装.cmd`，自动安装到 `%LOCALAPPDATA%\SpreadsheetToolsShare`，创建桌面入口和开机启动项，使用 `Ctrl+Shift+E`。仅支持 64 位 Windows，需自行安装 Excel 或 WPS 桌面版；卸载时双击包中的 `卸载.cmd`。

安装器支持 `-InstallRoot <路径> -NoShortcuts -NoLaunch`，供隔离安装验证；分享版脚本支持 `--self-test`，仅构建隐藏面板并报告启动结果，不连接或修改工作簿。分享版使用独立安装目录和启动项，建议同一电脑只运行一个占用该快捷键的面板版本。

双击安装/卸载入口使用包内运行环境执行 `setup.ahk`，无需 PowerShell；入口仅含 ASCII，避免批处理中文编码导致命令解析差异。安装前后均校验 SHA-256，错误通过弹窗和 `%LOCALAPPDATA%\SpreadsheetToolsShare-install.log` 显示，入口级错误记录于同目录的 `SpreadsheetToolsShare-launch.log`。安装无需关闭 Excel/WPS。原 PowerShell 脚本保留作为备用入口；原生安装器支持 `install/uninstall --root <以 SpreadsheetToolsShare 结尾的绝对路径> --shortcut-root <隔离快捷方式目录> --quiet --no-launch`，供测试安装、更新、快捷方式与卸载。

项目 `tests\` 目录提供无头 COM 自动化回归与性能基准测试脚本（测试过程不自动保存工作簿，跑完自动退出清理进程）：

```powershell
# 3. 导出选区信息（给 AI）冒烟测试
& "C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe" /ErrorStdOut tests\spreadsheet-export-smoke.ahk excel
```
